# Caesar Cipher – Python Project

## About the Project

This is a beginner Python project that encrypts and decrypts messages using the Caesar Cipher technique.

The program shifts letters through the alphabet according to a number entered by the user.

## Features

- Encrypt and decrypt messages.
- Choose the number of positions to shift.
- Preserve spaces, numbers, and punctuation.
- Handle alphabet wrap-around using the modulo operator (`% 26`).
- Reject invalid encryption or decryption choices.

## How to Run

1. Open `project3_cipher.py` in VS Code or another Python editor.
2. Run the Python file.
3. Select `e` to encrypt or `d` to decrypt.
4. Enter your message.
5. Enter the shift number.
6. View the result.
